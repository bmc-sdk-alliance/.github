# 中立社区 BMC SDK 开源托管平台

一个由多家 BMC 芯片原厂共同参与的中立开放社区：在统一的 **Linux 6.18 / U-Boot** 基线上协作，各厂商在自己的分支上自治维护。目标是让 BMC 厂商共享一套干净、可复现的上游基线，降低重复的 bring-up 与维护成本。

## 工作范围

- **单仓多分支**：`linux`、`u-boot` 各仅一个仓库，公共基线分支 `dev-6.18`，各厂商分支 `vendorA/6.18`、`vendorB/6.18`。
- **分支自治**：各厂商 Team 全权负责本厂商分支的日常合入、评审与维护。
- **基线共识**：只有公共基线 `dev-6.18` 的变更需要跨厂商确认。
- **二进制不外流**：固件等二进制保留在各厂商官方开源仓库，社区仓只保存引用 URL 与 SHA256 校验值。
- **外围工具独立建仓**：烧录、诊断等工具放在独立仓库，与 Kernel / U-Boot 物理隔离。

## 参与方式

1. 阅读 [CONTRIBUTING.md](https://github.com/bmc-sdk-alliance/.github/blob/main/CONTRIBUTING.md)：分支模型、厂商负责人列表、DCO 签署、二进制哈希校验、漏洞反馈渠道。
2. 联系对应厂商团队：`@bmc-sdk-alliance/vendor-a-team`、`@bmc-sdk-alliance/vendor-b-team`（占位名，随厂商确认后调整）。
3. 提交 PR 时使用统一的 [PULL_REQUEST_TEMPLATE.md](https://github.com/bmc-sdk-alliance/.github/blob/main/PULL_REQUEST_TEMPLATE.md) 自查清单；所有提交必须包含 `Signed-off-by`。
